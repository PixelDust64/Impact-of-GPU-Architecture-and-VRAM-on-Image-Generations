
# Heterogeneous Edge Image Generation

Reproducibility repository for the paper:

**"A Study of Energy Efficiency in Heterogeneous Edge Nodes: Impact of GPU Architecture and VRAM on Image Generation"**




## Evaluated Hardware

The experiments include heterogeneous GPUs and edge-oriented devices, including:

* NVIDIA RTX 5090
* NVIDIA RTX 5070
* NVIDIA RTX 3060M
* AMD Radeon Pro VII

## Models

* Stable Diffusion XL (SDXL)
* Z-Image Turbo

## Included Metadata

The images on repository include:

* Prompt
* Negative prompt
* Seed
* CFG scale
* Scheduler
* Sampling steps
* Resolution

## Purpose

This repository was created to improve reproducibility and transparency of the experimental results presented in the paper.
